# ⌨️ Hotkey Toolips

Легкий десктопний застосунок на **C++**, **Dear ImGui** та **Windows API**, створений для керування глобальними гарячими клавішами, швидкого запуску програм та локального тролінгу друзів під час демонстрації екрана (наприклад, раптовий показ випадкових картинок або відео без рамок).

> ⚠️ **Примітка розробника:** Будемо чесними, близько 30% цього коду було згенеровано за допомогою ШІ, тому що писати шаблонний GUI-код з нуля — це заняття для людей, у яких занадто багато вільного часу. Так, деякі частини жорстко захардкоджені для моєї власної зручності. Чи буду я колись робити рефакторинг, щоб усе було ідеально чисто? Можливо, колись.

## 🚀 Основні можливості

* **Глобальні бінди:** Призначай клавіші на конкретні дії та викликай їх глобально за допомогою низькорівневих перевірок Windows API (`GetAsyncKeyState`).
* **Запуск медіа та програм:** Миттєво відкривай URL-посилання, запускай `.exe` файли або відтворюй зображення та відео.
* **Безрамковий повноекранний режим (Тролінг-мод):** Рендеринг зображень (через GDI+) та відео (через MCI) на весь екран без рамок поверх усіх інших вікон. Ідеально для скрімерів, мемів або швидкого показу референсів.
* **Підтримка Drag & Drop:** Просто перетягни файли у вікно — інструмент автоматично обробить їх і скопіює в локальну директорію.
* **Динамічне сканування файлів:** Закинь файли в локальну папку `zalejnost/` і натисни `update` — інструмент автоматично знайде нові медіафайли без перезапуску.
* **Інтеграція в System Tray:** Акуратно ховається у фоновий трей Windows, щоб панель завдань залишалася чистою. Клік правою кнопкою миші, щоб відкрити або вийти.
* **Підтримка автозавантаження:** Можна налаштувати на автоматичний запуск у згорнутому вигляді разом із Windows.

## 🛠 Технологічний стек

* **Мова:** C++17
* **GUI:** Dear ImGui (GLFW + OpenGL2 backend)
* **Взаємодія з ОС:** Windows API (WinAPI, GDI+, ShellAPI, winmm)
* **Система збірки:** CMake
* **Збереження даних:** Легкі локальні `.txt` файли для списків та конфігурацій.

## ⚙️ Як зібрати (Build)

Склонуй репозиторій та збери його за допомогою CMake:

```bash
git clone [https://github.com/osFERPHY/Hotkey_Tolips.git](https://github.com/osFERPHY/Hotkey_Tolips.git)
cd Hotkey_Tolips
mkdir build
cd build
cmake ..
cmake --build . --config Release
```

## 📂 Структура зберігання

Програма автоматично створює директорію `zalejnost/` поруч із виконуваним файлом. Усі медіафайли або програми, перетягнуті у застосунок, зберігаються тут, що робить інструмент повністю портативним і зручним для резервного копіювання.
